# 息壤看板查询

沿用当前任务的 Browser Use 指引与已有息壤页。效果多维分析入口：`https://ds.ad.xiaomi.com/miui-soil-platform/index.html#/olapMultiQuery/adEffect/9`。

1. 从请求确定日期、分组、筛选、指标及交付范围；先读已有配置，正确的直接复用。用户指定浏览器时保持该通道。指标标签不自动等于业务口径：“emi效果收入”不能直接称为财务消耗，单位也不能默认是元；以页面说明或用户证据为准，未确认就保留原名、注明未知。
2. 配置维度/指标时，现场若有明确可见的等价菜单或添加入口，优先使用；否则依据当前页面拖入对应区域。以目标标签出现为完成证据，不能以动作成功代替。拖一次无效果就重新观察源、目标、弹窗及等价路径；没有新证据不重复拖。需要中文名称时选名称子项，不能交付数字 ID 冒充名称。仅遇到控件选择或口径疑问时读 [控件与口径](references/olap-controls.md)。
3. 日期必须精确覆盖请求边界；快捷项匹配才用，选后确认并读回起止时间。任意范围按现场日历设置，不用近似日期替代。无效输入不反复填写。查询前核对实际日期、分组、筛选、指标；配置变动后只修正偏差。
4. 提交后取得本轮查询完成、结果已更新的证据再读数，避免读到旧表。按请求取所需行、列或汇总；明确要求全量/全部页时覆盖完整结果，不能将当前页称为全量。需导出时使用真实导出并验证文件可解析，不能把页面摘要自制成“原始导出”。仅涉及导出、跨页或中断续读时读 [结果完整性](references/results.md)。
5. 交付实际日期、分组/筛选、指标原名及已确认单位、所需结果；文件任务附真实文件位置。部分结果说明已读范围与缺口。请求所需证据齐全即停止，不额外全屏、截图、重复查询或扩展分析；用户明确要求截图时只取所需证据。

这些是站点操作提示，不证明拖拽根因已修复；页面变化时以现场为准。
