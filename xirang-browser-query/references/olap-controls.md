# 息壤控件与口径

仅在对应控件或口径有疑问时读取。以下控件来自历史现场，先核对当前页面；不照抄未出现的菜单或选择器。

## 维度与指标

| 区域 | 历史 selector | 完成证据 |
| --- | --- | --- |
| 筛选 | `.dragArea.filters` | 条件、选值符合请求 |
| 分组 | `.dragArea.groups` | 目标分组标签出现 |
| 指标 | `.dragArea.measures` | 目标指标标签出现 |

树叶曾为 `.el-tree-node__content`；先确认唯一目标。部分维度出现 `.detail-popup`，选所需子项并在该可见弹窗确认；无弹窗时直接核对目标区标签。优先现场已观察到的等价菜单路径，不能猜菜单名。

仅有 ID 时，可核对分组区对应 `.base-query-item .display-label` 是否能打开子项；选择名称后确认并重查。媒体名称历史字段为 `media_type_name`，效果一级行业名称为 `industry_level1_name`；不要选第一个同名或隐藏控件。

拖拽无效果后检查源、目标及弹窗，再决定有证据支持的其他路径。不要用合成事件或直接改页面状态冒充配置成功；通用拖拽能力存在不等于本站点业务效果已修复。

## 日期

历史入口 `Start date & time` 打开 `.date-time-range-picker`，快捷项为 `.short-btn`；选快捷项后仍需面板内“确定”。该自定义控件曾有填写无效情况，读回不一致就观察日历月份、日期和时间控件，不循环同一填写动作。修改维度可能影响日期，以实际边界为准。

## 口径

- “emi效果收入”是历史指标标签；定义、是否对应用户所称消耗及单位均需证据，未知不换名、不换算。
- 分媒体可用“媒体-媒体名称”，不必额外补查媒体大类。
- “运营二级自定义行业”历史上无需扩展弹窗、返回名称；不要混同运营一级或效果行业。
- 曝光、点击等按任务选择，不能拿默认指标冒充。
