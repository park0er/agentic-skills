# 结果完整性

仅在导出、跨页或中断续读时读取；交付范围由请求决定。

## 真实导出

确认入口导出全部结果还是当前页。按当前 Browser Use 指引接住实际触发动作的下载；打开菜单或弹窗不代表下载完成。异步任务需等真实下载链接。超时先查已有任务和下载状态，不立即重复提交。

保存后检查实际文件存在、非空、类型可解析。CSV 按 CSV 解析，XLSX 选真实数据表；不能只按文本行数计数，也不能把错误/登录 HTML 改名冒充结果。核对表头、条件、单位、数据行数及截断情况；与界面总数不符要解释或继续查证。未取得文件就说明导出未完成，不能用整理的摘要代替原始导出。

## 全量分页

无完整导出，或用户明确要求逐页读取/与导出交叉核对时，读取全部页；已有完整导出且无逐页要求时不额外遍历。

1. 只定位结果主表，核对表头、总数、当前页和页大小；排除固定列副本，不扫全页面所有表。
2. 按实际总数与页大小确定覆盖范围。翻页后验证页码改变且本页加载完成，再读取；历史下一页控件为 `.btn-next`，仅当前确实存在且可用时使用。
3. 每页保存行数、页码、查询条件与文件位置；成功保存才记为完成。相同页码不重复追加，不用整行去重掩盖重复读取，合法行可能相同。
4. 累计行数与界面总数核对。缺页、超时、总数变化或执行预算不足时说明部分范围，不设固定页数上限却称全量。

## 中断续读

文件与已保存页码是进度依据，页面内存不是。恢复后核对条件、页码及查询状态仍对应同一查询，只续读剩余范围；条件被改变时不能直接追加旧结果。完成请求后停止，不为展示再查一次或截图。
