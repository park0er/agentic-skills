# NotebookLM 功能速查表

命令基于 `notebooklm-cli` / `nlm` 0.1.12。实际执行前可运行 `nlm --ai` 或 `nlm <command> --help` 校验当前版本。

## 会话与配置

| 命令 | 说明 | 自动执行 |
|---|---|---|
| `nlm --version` | 查看 CLI 版本 | ✅ |
| `nlm --ai` | 输出 AI 友好的完整命令参考 | ✅ |
| `nlm login` | 打开 Chrome 登录 Google | 需要用户操作 |
| `nlm login --profile work` | 登录指定 profile | 需要用户操作 |
| `nlm auth status` | 检查认证状态 | ✅ |
| `nlm auth list` | 列出 profiles | ✅ |
| `nlm auth delete <profile> --confirm` | 删除 profile | ❌ |
| `nlm config show` | 查看配置 | ✅ |
| `nlm config show --json` | JSON 配置 | ✅ |
| `nlm config get <key>` | 读取配置项 | ✅ |
| `nlm config set <key> <value>` | 修改配置项 | 视影响确认 |

## 笔记本

| 命令 | 说明 | 自动执行 |
|---|---|---|
| `nlm notebook list` | 列出笔记本 | ✅ |
| `nlm notebook list --json` | JSON 格式列出 | ✅ |
| `nlm notebook list --title` | 输出 ID 和标题 | ✅ |
| `nlm notebook create "标题"` | 创建笔记本 | ✅ |
| `nlm notebook get <id>` | 查看详情 | ✅ |
| `nlm notebook describe <id>` | AI 摘要和建议主题 | ✅ |
| `nlm notebook rename <id> "新标题"` | 重命名 | ✅ |
| `nlm notebook delete <id> --confirm` | 永久删除 | ❌ |
| `nlm notebook query <id> "问题"` | 一次性问答 | ✅ |
| `nlm notebook query <id> "问题" --conversation-id <cid>` | 继续对话 | ✅ |
| `nlm notebook query <id> "问题" --source-ids <ids>` | 限定来源问答 | ✅ |

## 来源

| 命令 | 说明 | 自动执行 |
|---|---|---|
| `nlm source list <notebook_id>` | 列出来源 | ✅ |
| `nlm source list <notebook_id> --full` | 完整来源信息 | ✅ |
| `nlm source list <notebook_id> --url` | 输出来源 ID 和 URL | ✅ |
| `nlm source add <notebook_id> --url "https://..."` | 添加网页 URL | ✅ |
| `nlm source add <notebook_id> --youtube "https://youtube.com/..."` | 添加 YouTube | ✅ |
| `nlm source add <notebook_id> --drive "<doc_id>" --type doc` | 添加 Google Drive 文档 | ✅ |
| `nlm source add <notebook_id> --text "正文" --title "标题"` | 添加粘贴文本 | ✅ |
| `nlm source get <source_id>` | 来源元数据 | ✅ |
| `nlm source describe <source_id>` | AI 来源摘要 | ✅ |
| `nlm source content <source_id>` | 原始文本内容 | ✅ |
| `nlm source content <source_id> --output file.txt` | 导出来源文本 | ✅ |
| `nlm source stale <notebook_id>` | 列出过期 Drive 来源 | ✅ |
| `nlm source sync <notebook_id> --confirm` | 同步过期 Drive 来源 | ❌ |
| `nlm source delete <source_id> --confirm` | 永久删除来源 | ❌ |

当前版本不支持直接上传本地 PDF/Word/音视频文件路径；改用 Google Drive 来源或 `--text`。

## 研究

| 命令 | 说明 | 自动执行 |
|---|---|---|
| `nlm research start "查询" --notebook-id <id>` | 快速网络研究 | ❌ |
| `nlm research start "查询" --notebook-id <id> --mode deep` | 深度网络研究 | ❌ |
| `nlm research start "查询" --notebook-id <id> --source drive` | Drive 研究 | ❌ |
| `nlm research status <id>` | 查看研究状态 | ✅ |
| `nlm research status <id> --max-wait 0` | 单次轮询 | ✅ |
| `nlm research status <id> --max-wait 300` | 等待完成 | 子任务内 ✅ |
| `nlm research import <id> <task_id>` | 导入全部研究来源 | ❌ |
| `nlm research import <id> <task_id> --indices 0,2,5` | 导入指定来源 | ❌ |

## Studio 产物

| 命令 | 说明 | 自动执行 |
|---|---|---|
| `nlm studio status <id>` | 查看所有产物状态 | ✅ |
| `nlm studio status <id> --json` | JSON 产物状态 | ✅ |
| `nlm studio status <id> --full` | 完整产物信息 | ✅ |
| `nlm studio delete <id> <artifact_id> --confirm` | 删除产物 | ❌ |

当前 `nlm` 0.1.12 没有通用 `download` 子命令。需要下载时先查 `nlm studio status <id> --full`，若 CLI 无下载能力，需通过 NotebookLM Web UI 或更换支持下载的工具完成。
