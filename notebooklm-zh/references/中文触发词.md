# 中文触发词索引

## 笔记本管理

| 你说 | 我执行 |
|---|---|
| "登录 NotebookLM" / "认证一下" | `nlm login` |
| "认证状态" / "登录了吗" / "能连上吗" | `nlm auth status` |
| "创建一个笔记本" / "建个笔记本" / "新笔记本" | `nlm notebook create "标题"` |
| "笔记本列表" / "有哪些笔记本" / "我有哪些笔记本" | `nlm notebook list --title` |
| "删除笔记本" / "删掉这个笔记本" | `nlm notebook delete <id> --confirm`（需确认） |
| "重命名笔记本" / "改名" | `nlm notebook rename <id> "新标题"` |
| "笔记本摘要" / "这个笔记本讲了什么" | `nlm notebook describe <id>` |
| "给这个笔记本起别名" | `nlm alias set <name> <notebook_id>` |

## 来源管理

| 你说 | 我执行 |
|---|---|
| "导入这个链接" / "添加这个网址" / "把这个网页加进去" | `nlm source add <notebook_id> --url "url"` |
| "导入这个 YouTube" / "分析这个视频" | `nlm source add <notebook_id> --youtube "youtube_url"` |
| "导入这个 Google 文档" / "加 Drive 文档" | `nlm source add <notebook_id> --drive "<doc_id>" --type doc` |
| "把这段文字加进去" | `nlm source add <notebook_id> --text "正文" --title "标题"` |
| "来源列表" / "有哪些来源" / "导入了什么" | `nlm source list <notebook_id> --full` |
| "来源原文" / "看下来源内容" | `nlm source content <source_id>` |
| "来源摘要" / "来源导读" | `nlm source describe <source_id>` |
| "删除来源" / "去掉这个来源" | `nlm source delete <source_id> --confirm`（需确认） |
| "研究一下 XX" / "帮我查查 XX" / "网上搜一下 XX" | `nlm research start "XX" --notebook-id <notebook_id>` |
| "深度研究 XX" / "全面调研 XX" | `nlm research start "XX" --notebook-id <notebook_id> --mode deep` |
| "导入研究结果" | `nlm research import <notebook_id> <task_id>`（需确认） |
