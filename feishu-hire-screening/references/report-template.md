# HTML 报告规范

单文件 HTML，零 CDN 依赖（只允许 Google Fonts 的 Noto Sans SC / Noto Serif SC）。
视觉系统沿用 Swiss-international：klein blue `#002FA7` + lemon `#FFED00` + safety orange `#FF6B00` + ink `#111`，背景暖白 `#fafaf7`。
硬边偏移阴影 `6px 6px 0 var(--klein)`，不用模糊阴影。标题左对齐，不居中。

若本机装有 `tariq-html` skill，直接复用它的 comparison / status-report 模板与 `scripts/validate.mjs`。

## 结构（固定 6 段）

| 段 | 内容 |
|---|---|
| Hero | eyebrow（岗位 · 届次 · 人数 · 日期）+ 标题 + lede（口径一句话说清）|
| TL;DR | lemon 底 + ink 边框。**先说池子的结构性事实**（例如"283 条里 279 条已终止"），再说"只挑三个就挑谁" |
| 统计条 | 5–6 个数字：总数 / 去重 / 入选 / 各档人数 / 仍在流程 |
| 分档卡片区 | 每档一个 section，卡片含姓名 + 性别 + AI 标签 + 🔥 + 教育栏 + **为什么进** + **短板** |
| 全量表 | 可筛选（档位 / AI / 性别）+ 点表头排序 + 实时计数 |
| 口径与边界 | 分档标准、性别是推测、被排除的是谁、我动过什么没动什么 |

## 卡片必备两段

```html
<p class="evi">为什么进：具体证据，带数字，不要形容词</p>
<p class="risk"><b>短板</b> 学校差一档 / 无对口经验 / AI 只是工具层 / 年龄偏大 / 曾被拒过</p>
```

**没有「短板」的卡片就是没做完。** 用户要能只看卡片下结论。

## 交互契约（约 30 行内联 JS）

- 筛选胶囊：档位 / AI 档 / 性别，组合生效，带「当前显示 N 人」计数
- 表头点击排序（数字与中文都要能排，`localeCompare(x,'zh')`）
- sticky 锚点导航 + scroll-spy

## 证据写法

- ✅ `RAG 召回 87%→92%、答案精度 75%→84%`
- ✅ `有效成片率 28.6%→76.2%，日消耗 3.1w`
- ❌ `AI 能力很强，有丰富的大模型经验`

数字来自简历原文；简历里写"预计"的要保留"预计"二字，不要替他确定。

## 隐私

- **不要**把手机号、邮箱、talent_id 放进 HTML（要发内网就更不能放）
- 发布前扫一遍：`grep -E '1[3-9][0-9]{9}|[\w.]+@[\w.]+|[0-9]{15,}'`
- 姓名 + 学校 + 经历本身仍是候选人信息；用 protofly 发内网时默认是 public，要提醒用户可以一条命令收紧成 private
