## 零、两层结构（先理解这个再看下面）

```
第一层  公司官方底线（27 届校招）—— 决定「能不能要」
        不满足的一律不自动通过。这层不是本人偏好，是公司定的，改动要有出处。

第二层  本人的档位与偏好 —— 决定「多想要、谁排前面、谁值得越档」
        比官方严。真正的自动通过门槛用这一层。
```

两层是**包含关系不是替代关系**：官方允许的范围比本人想要的宽。所以判断顺序是**先过官方底线，再过本人档位**。

**关键约束：AI 越档通道也不能越过官方底线。** 学校再怎么靠 AI 捞，也不能低于官方那条线。

真正最想要的那种人是：**对 AI 狂热、自驱、能自己攒出东西的聪明劲**。学校档位是筛选效率工具，不是目的。

## 一、第一层：公司官方底线（27 届校招）

来源：《小米集团 2027 届全球校园招聘手册【面试官版】》，校招策略转向"精招精培"。

### 1. 招聘范围（届次）

**2026-09-01 ～ 2027-08-31 毕业**的 2027 届海内外应届毕业生。

判定方法，按优先级：

1. **`education_list` 里最高学历的 `end_time`（毕业时间）落在窗口内** —— 首选，这是精确口径
2. `graduate_year` 只做交叉校验，**不能单独采信**（字段脏：有人填 2026 有人填 2027 有人空）
3. 上面两条都拿不准时，才退回用 `biz_create_time` 的投递批次聚类兜底

### 2. 年龄：不大于 26 岁

官方原文写"不大于 2N"。**N = 13，是校招生的初始职级**，所以 2×13 = **26 岁**。

### 3. 本硕 GAP 期：不大于 1 年

本科 `end_time` 与硕士 `start_time` 相差不超过 1 年。
**只有本科学历、不读研的人，这条不适用**，不要因此卡人。

### 4. 学校层级底线

**985 & 211 + QS 前 100 + 中科院 / 西安邮电大学**

- 国内 985 / 211：查 `references/domestic-985-211.md`（985 共 39 所、211 现存 112 所，已固化）
- 海外 / 港澳台：查 `references/qs-top100.md`（QS 2027 版，官方 Excel 生成）
- 两个特例：中国科学院（国科大及各研究所）、西安邮电大学

**这三个来源都查不到的院校 —— 普通一本、二本、双非、独立学院、民办本科 —— 一律不满足官方底线，不自动通过，AI 再强也不越。** 这类人列进报告让本人定。

不许靠记忆判断"是不是 211""是不是 QS100"，一定要查表。

### 5. 无心理风险

心理测评风险度为**"低"或"较低"**。测评结果在候选人详情页的笔试区。

### 6. 数据缺失时怎么办（这一节很重要，别搞反）

官方底线里的五条判据分两种性质：

| 判据 | 性质 | 读不到数据时 |
|---|---|---|
| 届次、学校层级 | **必须证明满足** | **不自动通过**（这两条定义了"是不是这个池子里的人"） |
| 年龄、本硕 GAP、心理测评 | **只能用来否决** | **不否决，照常自动通过**，但要在报告里标注"未取到" |

也就是说：**心理风险高 / 较高 → 禁止自动通过；没做过测评 → 该自动通过还是自动通过。** 年龄和 GAP 同理。

（年龄与 GAP 采用"只能否决"这一性质，是按心理测评那条的同类逻辑推定的；如需改成硬性必须证明，在这里改。）

### 7. 官方手册里**故意不收录**的两条

写在这里是为了防止以后有人又加回来：

- **"AI 能力：有过 AI 的使用经验"** —— 本人明确要求不收录。官方这条门槛远低于第三节的 AI 判据，混进来只会变成干扰项。AI 的判定一律走第三节。
- **"提升硕博占比"** —— 本人明确表示不用管。档位一律看本科，不因硕博调整。

## 二、第二层：本人的学校档位（自动通过的真正门槛，按**本科**判）

一律看**本科院校**，不看硕士刷上来的学历。国内外顶级名校都算，**不要求必须是海外**。

| 档 | 范围 | 默认是否进主名单 |
|---|---|---|
| **S** | 清华、北大 | 是 |
| **A** | 复旦、上海交大、浙大、南大、中科大、中国人民大学（华五 + 人大） | 是 |
| **H** | 本科海外 / 港澳台，**QS 前 50** | 是 |
| **H+** | 本科海外 / 港澳台，**QS 51–100** | **仅当 AI 特别过硬**（见第三节） |
| **B** | 顶级 985（武大、华科、中山、同济、北航、哈工大、西交、南开、天大、东南、厦大、北师大、北理工、华东师大、华南理工、中南、中国农大、西工大、电子科大） | **仅当 AI 特别过硬** |
| **C** | 其他 985 + 强 211 / 财经（川大、山大、吉大、大连理工、重大、湖大、兰大、东北大学、海大、西农、北邮、北交、央财、上财、贸大、中南财、中传、西电） | **仅当 AI 特别过硬** |

B / C 档列的是**典型代表，不是穷举**。落在 `domestic-985-211.md` 里但没被点名的 985 / 211 按 C 档处理。

海外本科 **QS 100 开外一律不达标**（与官方底线一致，也是本人的天花板）。

## 三、AI 与自驱（既是加分，也是越档判据）

### 1. AI 深度四档

**必须读简历全文判定，不许用关键词计数。**

| 档 | 判据 |
|---|---|
| **AI 核心** | 在 LLM / AIGC / Agent 产品上做过 0→1 或核心策略：微调、RAG、Prompt 工程 + 评测集、Agent / Skill 架构、模型指标优化、多模态链路 |
| **AI 强** | 有真实模型工程或成体系 AI 项目 / AI 能力落地（CNN/Transformer 建模、Kaggle、LangChain、LLM 打标、企业级 RAG） |
| **AI 有接触** | 简历里有 ML/AI 痕迹，但只是用过工具（Cursor、Vibe Coding、Claude）或课程项目 |
| **AI 无** | 基本没有 |

### 2. 自驱 / 对 AI 热衷（🔥 标记）

这一项和学校档位同等重要，**不是装饰性标签**。看得出**很强的自学动机**、对 AI 热衷甚至疯狂的，打 🔥：

- 自己攒项目并真上线（GitHub 公开、HuggingFace Spaces、个人作品集网站、个人桌面端 MVP）
- 黑客松、竞赛拿到名次
- 简历里自述"自学编程""AI Native 实践者"并有作品佐证
- 跨界跳进来并跑出结果（非科班但做出 AI 产品）
- 用 codex / Claude Code 给自己造工具解决真实痛点

### 3. 「AI 特别过硬」＝ 越档通行证（判据必须同时满足两条）

这是 H+ / B / C 档能进主名单的**唯一**理由。门槛故意定得高，不是"AI 还不错"就算：

1. **AI 深度 = `AI 核心` 档**（`AI 强` 不够）
2. **有 🔥 自驱证据**（第 2 条里至少命中一项，且有作品 / 名次 / 线上产物可指认）

**只满足一条不算越档。** 判定时必须在报告里写清楚：命中哪一条 AI 核心判据、哪一项 🔥 证据。写不出具体证据就是不满足。

**越档的下界是官方底线**（第一节第 4 条），不是无底洞。

## 四、岗位对口（只加分，不是门槛）

岗位对口**只影响排序和高亮，不决定放行**。而且"对口"的定义里 **AI 优先于广告**：

**AI / LLM / Agent 产品经历 > 广告 / 投放 / 变现 / 商业化策略经历 > 其他**

一个做过 Agent 产品但没碰过广告的人，比一个做过信息流投放但对 AI 无感的人更想要。非对口但学校达标的照样放行。

## 五、可入职时间（highlight 项）

官方导向里"实习优先"，落到本人这里的关注点是**能不能提前来实习**：

- 简历里写到**能提前入职 / 能尽早来实习 / 当前时间就可实习**的，**单独 highlight 出来**
- **越早能来的越要标出来**，可以的话按可入职时间早晚给个排序参考

这是 highlight 项，**不是门槛也不是越档理由**。

## 六、排序

1. 档位（S → A → H → H+ → B → C）
2. AI 深度（核心 → 强 → 有接触 → 无）
3. **男性优先**
4. 同档内按学校、姓名

**越档进来的人单独标 `AI 越档`**，排在其原本档位的位置上，不要混进 S/A/H 里假装同档——本人要能一眼看出"这个人是靠 AI 捞进来的"。

## 七、输出要求

- **单文件 HTML 报告**（Swiss 视觉系统，见 `report-template.md`），卡片 + 可筛选全量表
- 每人必须同时写 **为什么进** 和 **短板**
- **对话回复里每个档位都要列全名字**，不能只讲高档位、把其余人埋在 HTML 里
- 明确报告"共 N 人，点名 M 个，剩下的是谁"
- 必须写明用的是 **QS 哪一版**（见 `qs-top100.md` 顶部版本号）
- 官方底线里**没取到数据的项要逐项标注**（年龄未知 / 未做心理测评 / 学历时间缺失）
- 性别是推测的，必须标注，并说明判不准的人数

## 八、已知的个人偏好与雷区

- **讨厌信息被悄悄跳过**。宁可列得长，也不要自己判断后不说。
- 要**诚实标注不确定**：推测就说推测，没验证就说没验证。QS / 211 查不到就说查不到，不要猜。
- 关心**池子本身的真相**：比如"这批 283 条里 279 条已终止"这种结构性事实比名单本身更重要，要先说。
- **抢人是有时间竞争的**：同一个候选人多个部门在看，晚点通过就可能被别人先锁走，后面还要 PK。所以对够格的人**倾向于尽快放行**，宁可多放一个进下一轮，也不要因为犹豫把人丢掉。
- 反过来，**拒绝要慎重**：点「不通过」不可逆，拿不准就留着别动。
